# Inam Ul Haq: Portfolio

Personal portfolio site: Solution Architect for Salesforce and .NET platforms.

**Live:** https://<your-github-username>.github.io

## Deploy on GitHub Pages

1. Create a **public** repo named exactly `<your-github-username>.github.io`.
2. Upload `index.html`, this `README.md` and your `resume.pdf` to the root of the repo.
3. Open **Settings → Pages**, set Source to *Deploy from a branch*, choose `main` and `/ (root)`, then click Save.
4. The site goes live at `https://<your-github-username>.github.io` within a minute or two.

## Files

- `index.html`: the whole site (plain HTML and CSS, no build step)
- `resume.pdf`: linked from the "Download resume" button. Add your current resume under this exact name.

## Optional: custom domain

Buy a domain (e.g. `inamulhaq.dev`), add it under **Settings → Pages → Custom domain**, and point a CNAME record at `<your-github-username>.github.io`.
